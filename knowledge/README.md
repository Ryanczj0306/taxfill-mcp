# Knowledge packs

Tax law as versioned, cited data. Every number the engine uses — brackets, deductions, credit phase-outs, thresholds,
mailing addresses, payment options — comes from these files, and every topic cites an official source. The engine
never falls back to model memory: when a year or block is not here it refuses, and points the agent to the freshness
protocol — the agent then resolves the value from the official sources `get_sources` returns, and cites it.

```
knowledge/
├── federal/<year>.yaml        # federal tax data per year; a planning year is marked provisional (projection only)
├── states/<st>/<year>.yaml    # each income-tax state: rates, credits, residency rules, filing requirement, addresses
├── states/no_income_tax.yaml  # the states with nothing to file for wages, with their narrow exceptions
├── treaties/<country>.yaml    # income-tax treaty articles used by the treaty-benefit math
├── forms/                     # code tables: W-2 box 12 codes, 1099-R distribution codes
├── sources.yaml               # the official .gov source registry per topic (what `get_sources` returns)
├── sources_states.yaml        # the per-state source registry — GENERATED by scripts/assemble_state_sources.py
└── pitfalls.yaml              # every bug ever found, each with a permanent countermeasure and a regression test
```

Which years ship is listed at the bottom of [docs/COVERAGE.md](../docs/COVERAGE.md). The rules for adding or changing
knowledge — no topic without a source, no guessed numbers ahead of final guidance — are in
[CONTRIBUTING](../.github/CONTRIBUTING.md#knowledge-packs-and-sources).
