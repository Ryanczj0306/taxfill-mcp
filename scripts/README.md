# Maintainer scripts

Run them from the repo root with `uv run python scripts/<name>.py`. None is needed to *use* taxfill.

| Script | What it does |
|---|---|
| `sync_test_count.py` | Keeps the test count quoted in the README badge and the roadmap equal to `pytest --collect-only` (`--write` / `--check`; CI runs `--check`) |
| `sync_doc_counts.py` | Same for every other quoted number (tools, calc ops, document kinds, packs), and generates the tables in `docs/COVERAGE.md` and the next release's coverage lines in `docs/CHANGELOG.md` |
| `sync_bundle_manifest.py` | Keeps the `.mcpb` bundle manifest's calc entry equal to the running server (a test checks the tool names) |
| `check_drift.py` | Freshness check: re-fetches the official sources, blanks and addresses (the weekly freshness workflow) |
| `check_quotes.py` | Quote-verbatim checker (Phase K JK23): every quoted span in the knowledge packs (state prose, federal `form_lines` captions, v2 `Quote`s) against its cited source text, fetched once and cached by url + sha256 (`.cache/quotes`; a URL in the blank cache is read from there). Reports VERBATIM / MISMATCH (closest passage, class) / UNCHECKED (reason); report mode exits 0 (the weekly freshness workflow), `--strict` exits 1 on a MISMATCH (JK26), `--json` writes the full report, `--offline` reads only the caches. Mismatches go to a JS2c-style fix tranche (`.github/CONTRIBUTING.md`). Phase K JK31: a MISMATCH re-read and found printed (the text layer differs: a page break's running head, columns read across) is closed in `check_quotes_closed.yaml` with its reason and is reported CLOSED; a closure that matches no MISMATCH is stale and fails `--strict`. A subset font that numbers its glyphs 29 below their letters (Arkansas DFA's forms) is decoded; a credit names a second source in `citations` |
| `freshness_quarantine.py` + `.yaml` | Known freshness reds behind an expiring allowlist, so only a NEW red fails |
| `check_finals.py` | Watches for the IRS final revision of each form a draft pack mirrors; opens the `ty<year>-finals: re-pin now` issue (JT6's trigger) |
| `check_watches.py` | The named watches (Phase K JK8), each filing its own issue: the irs-dft Schedule NEC / OI (Form 1040-NR) drafts re-posted newer than the recorded 2025 ones (JT5g), the IRS news release for the next year's inflation-adjustments Rev. Proc. (recorded for JT6, which authors the next year's knowledge after this year flips), a new digest at `irs-pdf/<form>.pdf` for each non-draft pack of the year (re-pin), and each tier-1 state's blank (JS7a: a 200 whose first page prints the year; a 403 host such as mass.gov is BLIND, listed to check by hand). The year is the oldest provisional federal year. A blind-only issue is titled blind; closing an issue acknowledges it until something new appears. `--dry-run` prints every target; a transient failure exits 1. Runs in `finals.yml` after `check_finals.py` |
| `scaffold_state_year.py` | Starts a state form-pack year: derives and probes candidate blank-PDF URLs, triages each form against its base year; `--tier1` limits it to the tier-1 states |
| `state_discovery_rows.json` | The verified blank-URL discoveries `scaffold_state_year.py --rows` consumes |
| `tier1_states.yaml` | The tier-1 state triage table (Phase K JK9): the income-tax jurisdictions ranked by IRS SOI return count (cited table, sha256), the tier-1 cut, and per tier-1 state the resident and NR/PY forms, the amend route (cited page) and the amended indicator its 2025 pack maps. JS7a's TY2026 state sprint and JK8's state-blank watch read it; `test_tier1_states.py` checks every row against the packs and knowledge. The NRA-student weighting in it is a pending recommendation, not applied |
| `worklists/` | Dated `scaffold_state_year.py --out` work-lists, e.g. `tier1_ty2026_2026-10-24.json` (the tier-1 TY2026 candidates, probed before the 2026 blanks posted: re-run it when they do) |
| `introspect_pdf.py` | Dumps a blank AcroForm's widgets, for authoring a new pack |
| `audit_pack.py` | Field-map audit harness for one pack |
| `make_sample_w2.py` | Renders the demo-persona sample W-2 (`docs/samples/w2_2025_synthetic.pdf` / `.png`) the user guide's walkthrough, ACCEPTANCE and DEMO use, from the figures at its top; re-run it when the 2025 wage base or FICA rates change (`test_sample_w2.py` fails until you do) |
| `stage_data.py` | Copies `knowledge/` and `formpacks/` into the core package before a build (release step) |
| `release_smoke.py` | Checks an installed wheel against the checkout it was built from: packs per jurisdiction-year, every staged data file, the state knowledge years, the pinned tool set (CI's packaging job and `docs/dev/PUBLISHING.md`; run it with the wheel's interpreter, outside the repo) |
| `release_notes.py` | Checks a release tag against the repo (every version site, a public version, a dated `docs/CHANGELOG.md` section) and prints that section as the GitHub release notes (the first step of `.github/workflows/release.yml`) |
| `bundle_probe.py` | Launches an unpacked `.mcpb` bundle with its own manifest command and checks it answers MCP `initialize` + `tools/list` with exactly the manifest's tools (`.github/workflows/release.yml`, against the published server, before the bundle is attached) |
| `golden_snapshots.py` | Snapshots what every state-knowledge reader returns (the `state_tax` calc op, `state_scope`, `filing_summary`, `file_and_pay`, `get_sources`) for every state jurisdiction-year, into `packages/core/tests/goldens/state_knowledge/` (`--write` / `--check`; `test_state_knowledge_goldens.py` runs the check). Re-run `--write` only when a knowledge change is meant to change the output, and review the diff |
| `golden_pack_path.py` | The pack-path golden (Phase K JK16b, the KG8 gate for the tools the no-pack fallback rides): `get_form_map` over every shipped pack, today's pack-path refusal texts, and `fetch_blank` -> `fill_form` -> `verify_form` -> `verify_filing` on synthetic demo packs through the real loaders (a temporary `TAXFILL_DATA_DIR` and `TAXFILL_BLANKS_CACHE`; blanks in `packages/core/tests/fixtures/pack_path_golden/`), into `packages/core/tests/goldens/pack_path/` (`--write` / `--check`; `test_pack_path_golden.py` runs the check). Re-run `--write` only for a pack-path wrong-value fix, and review the diff |
| `assemble_state_sources.py` | Regenerates `knowledge/sources_states.yaml` from the state knowledge packs' own citations; re-run it after changing a state pack's citations (`--check` runs in the test suite) |
| `hoist_state_sources.py` | Copies a TY2025+ state pack's .gov inline citations into its top-level `sources` table (one row per distinct topic and URL, every description kept), which the source registry is built from (Phase K JK20). Run once per new pack year; afterwards a new citation goes inline and into the table by hand (`test_state_sources_table.py` checks they agree). A pack that already has a table is skipped, so a TY2026+ v2 pack (written with its table) is too |
| `assemble_state_knowledge.py`, `assemble_state_tax_blocks.py`, `assemble_state_credits.py` | Build state knowledge packs, their `tax:` blocks and their credits from a cited research fetch (JSON) given on the command line — how the state knowledge was first assembled (schema v1, TY2025 and earlier). From TY2026 `assemble_state_knowledge.py --year 2026 --input FACTS [--tax-dir DIR] [--credits FILE]` writes each pack whole as schema v2 through `state_knowledge_v2_writer.py`, and the other two refuse a TY2026+ year |
| `state_knowledge_v2_writer.py` | The TY2026+ state pack writer (Phase K JK25): one cited fact set per state (input shape in its docstring) in, one `StateKnowledgeV2` pack out, its `sources` table built from the inline citations; refuses what v2 cannot carry honestly (a v1 block JK22 dropped, prose notes, a caveat that is neither a quote nor a not-modeled statement, a credit amount), naming the field to drop or reword; gates the written pack through the loader and the tax JSON's test vectors. Run through `assemble_state_knowledge.py` |
| `assemble_ca540.py`, `assemble_ca540nr.py` | One-time generators of the 2023 CA Form 540 / 540NR packs from a vision-mapping file that is not in the repo; kept as the record of how those packs were made |
